# لعبة الأسئلة

لعبة مسابقات عراقية للفرق، بيها 6,759 سؤال بـ17 قسم وأربع مستويات صعوبة (سهل، متوسط، صعب، صعب جداً).

## طرق اللعب
- **شاشة وحدة:** تلفزيون أو جوال واحد، والفرق تجاوب بالدور، ووياها وسائل المساعدة.
- **كل لاعب على جواله:** الشاشة تطلّع رمز، واللاعبين يدخلون بالرمز ويجاوبون سوية.
- **مع حكم أو بدونه:** الحكم يشوف الجواب ويتحكم بالنقاط، أو اللعبة تصحح وحدها.

## الملفات
- `index.html`: اللعبة كاملة.
- `questions.js`: بنك الأسئلة. كل سؤال بهذا الشكل: `[السؤال، الجواب الصحيح، خطأ1، خطأ2، خطأ3]`، والخيارات تتلخبط تلقائياً وقت اللعب.
- `bank-src/`: مصادر الأسئلة حسب القسم والمستوى، وسكربت `build_bank.js` اللي يفحصها ويجمعها بملف `questions.js`.
